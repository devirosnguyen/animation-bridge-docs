UCM Animation Bridge

A guide to the semi-automatic pipeline: type a prompt in Unity, get the animation on your rigged character in Cascadeur, refine it with AutoPhysics, then bring it into 3ds Max or Unity.

Overview

Unity: prompt + rig→ Python Bridge→ MoMask (Text-to-Motion)→ Blender: retarget to rig→ Cascadeur: edit + AutoPhysics→ FBX → 3ds Max / Unity
  • Semi-automatic: Cascadeur stays open. You run the commands from the Commands menu yourself; if the script server is running, jobs are loaded automatically.
  • Every stage communicates through a job folder: C:/AnimationBridgePipeline/jobs/<job_id>/ containing job.json, status.json, raw.bvh, raw.fbx, final.fbx and log.txt.
  • Job states: queued → generating → retargeting → waiting_cascadeur → in_cascadeur → exported, or error.

Installation

1. Text-to-Motion tools

Place these in E:\AnimationBridgeTools\:

  • venv\: Python 3.10 with CUDA-enabled PyTorch
  • momask\: MoMask source code and the HumanML3D model
  • .clip\: CLIP model
  • blender-4.2.9-windows-x64\: portable Blender, run headless for retargeting

2. Workspace and Cascadeur commands

pwsh -File install.ps1

This script creates C:/AnimationBridgePipeline/, copies Bridge/ to bridge/ and installs the commands into <Cascadeur>/resources/scripts/python/commands/AnimationBridge. Then choose Reload scripts in Cascadeur, or restart it.

3. Unity

Copy Unity/Assets/AnimationBridge/ into your project's Assets/ folder, then open Tools › Animation Bridge › Prompt To Cascadeur. In the Settings section, enter the Workspace root, the Python exe and the path to bridge.py.

4. 3ds Max (not yet tested)

Scripting › Run Script › 3dsMax/AnimationBridgeWatcher.ms, then turn on automatic watching.

Quick start (5 steps)

  1. In Cascadeur: Commands › MCP › Start script server (once each time you open Cascadeur).
  2. In Unity, in the Prompt To Cascadeur window: drag your character (for example Handyman) into the Rig field, choose the TextToMotion source, enter an English prompt, choose a duration, then click Generate.
  3. Wait about 10–15 seconds. Cascadeur opens the rig template and loads the animation onto the character.
  4. Edit the animation in Cascadeur and turn on AutoPhysics if needed.
  5. Run Commands › AnimationBridge › Bridge › Export Job.
If the script server is not running, or Cascadeur still has another job open, click Bridge › Load Next Job yourself.

Writing prompts for MoMask

MoMask is trained on HumanML3D: 22 joints, up to about 9.8 seconds. The model only understands body movement. It knows nothing about objects, machines or stories.

  • Describe movements, not events. Write “the right arm is pulled forward”, not “caught in a machine”.
  • Keep each sentence to 2–3 steps, joined with then in the order they happen.
  • Always say which hand or leg: right / left.
  • Use common verbs such as walks, runs, kicks, reaches, pulls back, struggles, bends over, falls, stumbles, holds the arm.
  • The same prompt with a different seed gives a different motion. Try 2–3 times and keep the best one.
PromptResult
A person's hand got caught in a crushing machineAlmost no movement, because the model does not understand it.
a person reaches forward with the right hand, then the right arm is suddenly pulled forward and the person struggles, pulling back hard with the whole bodyGood: reaches out, gets pulled forward, then struggles free.
a person kicks with the right legGood.
Details the model cannot produce (for example a hand pinned in place by a machine) are fixed in Cascadeur: pin the wrist to a point over the stuck frame range, then turn on AutoPhysics.

In Cascadeur

The commands are under Commands › AnimationBridge:

CommandWhat it does
Bridge › Load Next JobOpens the newest job in the waiting_cascadeur state. If rig/cascadeur_template.casc exists, it opens the template and loads the animation; otherwise it imports the whole FBX.
Bridge › Export JobSaves edited.casc and exports final.fbx together with a final.done flag. The Free edition cannot export FBX yet.
Bridge › Build Rig TemplateBuilds the rig template (Quick Rigging) automatically from rig/*_rig_base.fbx and rig/human_map.json.
Do not press Ctrl+S in a job tab. That tab was opened from the template, so saving overwrites the template. Use Export Job instead.

Rig template (once per character)

The template is the character after Quick Rigging, with a Center of mass ready for AutoPhysics.

  1. Export the rig in its rest pose (LOD0 only): 
    blender -b --factory-startup -P Bridge/text_to_motion/export_rig_base.py -- ^
  <rig.fbx> C:/AnimationBridgePipeline/rig/<Name>_rig_base.fbx
  2. Create rig/human_map.json in the form {"Hips": "<bone name>", ...}. You can copy this map from the human_map entry in the job.json of any job.
  3. In Cascadeur, run Bridge › Build Rig Template. It does the steps for you: create rig.qrigcasc → enter Rig Mode → Generate rig → leave Rig Mode → save rig/cascadeur_template.casc.

Doing it by hand (order matters)

  1. Click the Quick rigging tool button. This enters Rig Mode.
  2. In the QRT window, click ☰ → load the rig.qrigcasc template. Do not use the JSON rig import.
  3. Click Add rig elements.
  4. Click Generate rig in the left panel. Cascadeur leaves Rig Mode on its own.
  5. File › Save As → C:/AnimationBridgePipeline/rig/cascadeur_template.casc.
Generating outside Rig Mode reports Rig mode several animationInfo and creates nothing. This error has crashed Cascadeur before. Also, do not press Ctrl+Z right after Generate.

AutoPhysics

  1. Load the job through the template (see above). The character must have a Center of mass.
  2. Turn on the AutoPhysics button on the timeline toolbar. A green ghost appears: that is the physics-corrected version.
  3. Adjust keyframes until the green ghost looks right, then run Export Job.
If you see “Unable to select automatic center of mass”, the scene is probably not rigged. Load the job through the template, or build the template first.

Bringing results back to Unity / 3ds Max

  • Unity: when a job reaches exported, the clip is imported automatically into Assets/AnimationBridge/Imported/ with the rig's Avatar. Click Import to import it again.
  • 3ds Max: the watcher looks for the final.done file and merges the animation into the scene. The rig in Max should use regular bones, not Biped/CAT.
  • If you export the same job again, both sides reload it automatically.

Configuration: bridge_config.json

{
  "cascadeur_auto_load": true,
  "cascadeur_server": "http://127.0.0.1:8765",
  "retarget_to_rig": true,
  "tools_dir": "E:/AnimationBridgeTools",
  "momask_python": "E:/AnimationBridgeTools/venv/Scripts/python.exe",
  "momask_dir": "E:/AnimationBridgeTools/momask",
  "blender_exe": "E:/AnimationBridgeTools/blender-4.2.9-windows-x64/blender.exe"
}
  • cascadeur_auto_load: set to false to turn off automatic loading through the script server.
  • retarget_to_rig: set to false to export the MoMask skeleton (22 bones, no mesh) instead of retargeting to your rig.
  • The ANIM_BRIDGE_ROOT environment variable changes the workspace folder used by Cascadeur.

Troubleshooting

SymptomFix
The prompt has no effectThe File source is selected. Switch to TextToMotion.
Cascadeur does not load the job automaticallyRun MCP › Start script server. If an old job is still in_cascadeur, export or delete it, then click Load manually.
The animation barely movesThe prompt is too abstract. Rewrite it following Writing prompts.
The template cannot be savedThe template file is open in another tab. Close that tab and run the command again.
The job shows errorCheck log.txt in the job folder (Folder button).
Unity does not pick up new codeClick into the Unity window so it recompiles.

Current limitations

  • Cascadeur Free cannot export FBX. Export Job only saves edited.casc. After upgrading to Indie or Pro, the command exports final.fbx with no code changes.
  • MoMask and HumanML3D are for non-commercial use only.
  • MoMask only understands simple prompts and has no fingers (22 joints). HY-Motion 1.0 (Tencent Hunyuan) gives better quality and includes fingers, but needs about 16 GB of extra disk space for the Qwen3-8B text encoder. (Coming soon.)
  • The 3ds Max part has not been tested yet.
  • AutoPhysics still has to be turned on by hand after a job is loaded.
